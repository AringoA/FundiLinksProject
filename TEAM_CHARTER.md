## App summary
FundiLink connects employers who need short-term skilled labour with nearby workers ("fundis"). Employers can post jobs, and workers can browse listings and apply.

## Resource and action audit

### Users
- Register as a worker or employer.
- Log in and log out.
- Read role-specific navigation and pages.

### Jobs
- List jobs and filter by category, county/location, and active status.
- View a job's details and current availability.
- Create a job listing as an employer.
- Track listing status.

### Applications
- Create an application for an active job.
- List applications, optionally filtered by worker, job, or status.
- Read application status.
- Update a pending application.
- Cancel a pending application.
- Read a one-time server-sent status snapshot for an application.
